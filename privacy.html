Privacy policy

Effective 25 October 2026

ACE-PC Backup is a personal backup application operated by the owner of the PC. It copies selected local folders to that owner's Google Drive.

Information the application accesses

The local backup process reads files in the folders selected by the owner, including their names, contents, sizes and modification times. The process uploads those files to Google Drive.

The application requests https://www.googleapis.com/auth/drive.file. This permission lets it create files and access files created by, opened with or specifically shared with the application. It does not request unrestricted access to every file in the account.

To perform the backup, the application reads the IDs, names, parent folders, sizes, modification times and checksums of Drive files available to it. Setup may also check available Drive storage. Google issues access and refresh tokens after the owner grants permission.

How the information is used

Files and metadata are used to create and maintain the owner's backup, identify files that need uploading, verify transfers and report errors. The application does not use Google user data for advertising, profiling, sale or training AI models.

Google Drive changes are not applied to the PC's source files. A later backup may upload the PC copy again when a Drive copy has changed or been deleted.

Storage and access

Backup files are stored in the owner's Google Drive. OAuth credentials, refresh tokens, configuration and operational logs are stored locally in the owner's Windows profile. Logs may contain file paths, transfer results and error details. The application does not store the Google account password.

No separate developer-operated backup server receives the files or tokens. The PC owner can inspect their local files, logs and Drive backups. Access by other people depends on permissions the owner independently grants in Windows or Google Drive.

Data sharing and Google API policy

File contents and necessary metadata are transmitted to Google to provide Google Drive storage. Google processes them under its own terms and privacy policy. The backup process does not send them to GitHub or this public website.

ACE-PC Backup follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The backup mirrors selected PC folders in one direction. When the owner deletes, moves or renames an included local file, a later sync updates the Drive backup to match. Backup files removed by the sync are sent to Google Drive Trash. Excluded files are not managed by the sync. Updating a file may replace its current Drive version, subject to Google Drive's version history and retention behavior; this application does not provide a separate permanent snapshot archive.

The owner can disable the scheduled task to stop future uploads, remove backup files in Drive and remove local application configuration and logs. Google Drive trash and version retention are managed by Google.

Revoking access

The owner can remove ACE-PC Backup from their Google account's third-party connections. Revocation prevents continued authorized access. It does not itself delete local source files or existing Drive backups. Authorization must be granted again before future backups can run.

This website

This is a static information website hosted on GitHub Pages. It contains no login form, file upload, analytics script or application cookies. GitHub serves web requests under its own privacy statement.

Contact and changes

For questions or deletion requests, contact the application owner using the support email displayed in the Google authorization screen or your existing contact channel with the owner. Changes to this policy will be published here with an updated effective date.
