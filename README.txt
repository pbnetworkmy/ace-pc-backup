ACE-PC Backup public information website

Only the public application description, privacy policy, terms, stylesheet and
font are kept in this folder. No backup data, Google OAuth client files, refresh
tokens or Windows backup configuration belong in this repository.

GitHub Pages publication:
1. Create a new public repository named ace-pc-backup under the owner's account.
2. Upload this folder's contents to the main branch (index.html at repo root).
3. Repository Settings / Pages: Deploy from a branch, main, / (root), Save.
4. Wait for the Pages deployment to complete and check each published URL.

Google OAuth Branding values after publication:

Keep this public website separate from backup source resources.
