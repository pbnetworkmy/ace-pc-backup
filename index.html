ACE-PC Backup copies selected folders from the owner's Windows PC to a separate folder in their Google Drive.

Windows PCSelected local folders
Google DriveSeparate ACE-PC folder

One-way backup

The local application uses rclone to mirror selected PC folders to Drive. New files, edits, renames, moves and local deletions are reflected in the backup on a later scheduled run. Deleted backup files are sent to Google Drive Trash. Google Drive changes are never downloaded into the PC's source folders.

The owner signs in to their Google account and grants permission before the backup can run. Scheduled uploads require the PC to be on, the Windows user to be signed in, and an internet connection.

Access for the backup

ACE-PC Backup requests the Google Drive drive.file permission. It uses this access to create its backup folder, upload files, read file metadata and update files available to the application.

This is a personal application operated by the PC owner. It has no public registration, hosted backup server or shared access to other people's backups. This website provides information only and does not sign you in or accept file uploads.
